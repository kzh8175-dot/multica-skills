## 五、应用说明

1. **应用方式**：按岗位类别对照白名单，移除违反禁配规则的技能绑定（`agent skills set` 逐 agent 应用）。
2. **身份技能例外**：每个 agent 绑定其同名身份技能（persona），不在规则约束内，始终保留。
3. **合理跨域保留**：管理岗保留评审类（工程回顾/自动评审流水线/计划评审）；数据/文档/培训/售前岗保留图像类（信息图/幻灯片/知识漫画）；数据/工程岗保留安全护栏（命令安全护栏/编辑冻结）等。
4. **执行记录**：2026-08-17 共修正 20 个 agent 的错配绑定（财务/客服/SEO/内容/设计/文档/研究岗移除工程开发/调试/审查/安全类技能；设计岗移除代码审查/调试）。

## 六、维护建议

- 新增智能体：按岗位类别套用白名单分配技能，禁配技能不绑定。
- 新增技能：先归入技能类型，再决定可绑定的岗位类别，避免无约束扩散。
- 周期性核查：每月用规则引擎扫描一次，确保无越界绑定。
