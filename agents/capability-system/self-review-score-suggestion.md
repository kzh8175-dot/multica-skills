# 「评分建议」字段说明（P1-7 / KA-72）

> 配套：规则书《评分方案C rating-workflow-rulebook》§7.4 自评块升级 · 自评模板 `self-review-template.md`
> 版本：v1.1 · 维护：提示工程专家

## 1. 字段定义

| 属性 | 值 |
|------|----|
| 字段名 | `评分建议` |
| 所属块 | 【自评】块 |
| 位置 | 自评块**末尾**（`改进` 之后） |
| 取值 | 整数 **1-5** |
| 语法 | `- 评分建议：{1-5}` |
| 用途 | 供季度人评参考（R-21 判定配套） |

## 2. 取值含义

| 值 | 含义 |
|:---:|------|
| 5 | 完成度优秀、交付超出预期 |
| 4 | 完成度高，交付符合预期且质量良好 |
| 3 | 完成，交付基本达标，有可改进处 |
| 2 | 部分完成，交付不完整或质量明显不足 |
| 1 | 任务基本未完成或交付质量差 |

取值必须为整数，禁止小数、分数或文字描述（如 `3.5`、`B+`）。

## 3. 在自评块中的位置（规则书 §7.4）

```markdown
【自评】
- 完成度：✅ / ⚠️ / ❌
- 新技能：...
- 挑战：...
- 改进：...
- 评分建议：{本任务自评得分1-5}
```

## 4. 用途与边界

- **用途**：评分人在季度人评时，将该字段作为参考信号校准「交付质量 / 专业能力 / 自我优化」等维度分；与 R-21 判定配套使用。
- **边界 1（不自动加分）**：本字段**不**等于自动积分。R-21 高质量自评固定 +5，与评分建议取值无关。
- **边界 2（不写入 rating.points）**：智能体**严禁**按自己的评分建议写 `rating.points` 或 `rating.event`。评分建议只出现在【自评】块文本中。
- **边界 3（如实自评）**：应基于任务实际完成度给出建议值。虚高（一律 5 分）或虚低均属失真，后续防失真机制（P1-10 R-72 缺自评降档）对缺失/失真情形做约束。

## 5. 缺失处理

- 缺自评（含缺评分建议）按规则书 **R-32** 处理：季度内 ≥2 次 → 等级**降一档**（见 P1-10 防失真机制自动化）。
- 因此「评分建议」为自评块**必填字段**，不是可选项。
