# 任务后自评模板

这个模板用于每次任务完成后进行自我评估和更新能力档案。
版本：v1.1（P1-7 · 自评块新增「评分建议」字段，配套规则书 §7.4）

## 使用时机

每次智能体完成任务后，使用此模板进行反思和记录。

---

## 一、任务最终回复末尾的自评块（必填）

在任务最终回复末尾附加以下自评格式（规则书 §7.4，`{1-5}` 为整数自评得分建议）：

```markdown
---
【自评】
- 完成度：✅ / ⚠️ / ❌
- 新技能：...
- 挑战：...
- 改进：...
- 评分建议：{1-5}
---
```

> **「评分建议」字段**（P1-7 新增，置于自评块**末尾**）：
> - **取值**：整数 **1-5**。1=任务基本未完成或质量差；5=完成度优秀、超出预期。
> - **用途**：供季度人评参考（与 R-21 判定配套）。评分人据此校准主观维度分，**不代表自动加分，也不改变 R-21 固定 +5 的积分**。
> - **规则**：如实自评，不虚高、不低估；仅作人评参考信号，不得据此自行写 `rating.points`。
> - **缺失影响**：缺自评（含缺评分建议）按规则书 R-32 处理（季度内 ≥2 次 → 等级降一档，见 P1-10）。

字段完整取值范围与用途说明见 `self-review-score-suggestion.md`。

## 九、评分积分记录（Rating Metadata）

任务完成后，按权限写入评分 metadata（方案C 第2阶段接入）：

### 本任务可写入的事件（智能体仅限 self-optimization 类）

| 规则 | 事件 | 积分 | 触发条件 |
|------|------|:---:|---------|
| R-21 | 高质量自评 | +5 | 回复含【自评】且含≥2项内容 |
| R-22 | 更新能力档案 | +5 | 更新 capabilities.md 后 |
| R-23 | 协作好评 | +5 | 收到协作好评后 |

### 写入命令（对当前任务 issue 执行）

```bash
multica issue metadata set <issue-id> --key rating.trigger --value "agent" --type string
multica issue metadata set <issue-id> --key rating.event --value "R-21:自评" --type string
multica issue metadata set <issue-id> --key rating.points --value 5 --type number
multica issue metadata set <issue-id> --key rating.status --value "pending" --type string
```

### 权限边界

- ⛔ 仅可写入 R-21/R-22/R-23 三项（trigger=agent）
- ⛔ 行为类事件（R-01~R-13, R-31~R-33）由负责人 review 时写入（trigger=reviewer）
- ⛔ **严禁将「评分建议」字段作为 rating.points 写入**——评分建议仅供人评参考，积分以规则书固定值为准
- ⛔ 严禁设置 rating.trigger=reviewer
- ⛔ 无法确定 issue-id 时跳过写入

### 结算状态说明

- **pending**: 已写入待结算 → 结算器自动处理
- **credited**: 已入账
- **escalated**: 升级最高决策者（资深战略领导者）裁决
