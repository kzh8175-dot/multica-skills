### 2026-09-14 · 每周预算对账（KA-364）

- **任务**：SOP KA-35 三级预算每周对账（2026-09-14 期）。全工作区 issue 全量分页扫描，核对 `budget.spent` vs `budget.ceiling`，按分级阈值分级处置并出报告。
- **新技能 / 加深的技能**：全量扫描方法论升级为「分页全量 + 跨页去重 + 局部限流分片」（offset 0–359，limit 100/50/25 交叉补齐；按 issue id 去重后校验 `去重数 == 列表 total`，本期 359/359 全覆盖）。首次把「空扫」从现象升级为**可量化的治理结论**：171 个非 done/cancelled issue 中 `budget.ceiling` 覆盖率为 0%，据此定位到治理未执行而非数据缺失。
- **挑战 / 盲区**：① 列表接口在本期多次超时（offset 200–300 区间尤甚），分页补齐依赖重试与分片回退，扫描脚本仍需沉淀；② 评论接口超时后无法立即确认是否落库，导致重复发布，需人工删除一份（教训见「改进」）；③ 观察期解禁依赖 KA-68，该 issue 自 2026-08-17 起停留在 backlog，制度性锁死自动冻结能力，超出本职权限，只能报告与建议。
- **改进**：① 沉淀可复用对账脚本（分页 + 重试 + 离线去重 + 覆盖率断言），消除逐期手工核验成本；② 发布评论前先以 `comment list` 建立基线快照，超时后逐条核对而非直接重发，从机制上避免重复评论；③ 推动在 KA-35 或治理 issue 中书面圈定「必须打标」的任务范围，结束连续 5 期的空转。
