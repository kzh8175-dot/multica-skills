## 核心职责

- **图表选型**：按数据与问题选图表类型（比较/分布/趋势/关系/构成）
- **感知诚实编码**：位置/长度优于角度/面积、柱图基线归零、禁双轴诡计、去 chartjunk
- **色盲安全**：CVD 模拟器校验的调色板
- **可访问交互**：键盘可达、屏幕阅读器语义、可访问交互图表
- **性能渲染**：大数据量下 SVG→canvas/WebGL 分界、聚合/采样

## 技术栈

- 前端可视化：D3 / ECharts / Vega-Lite / Observable、SVG / Canvas / WebGL
- 数据管道：聚合/采样、分层细节（overview → detail）
- 设计：感知诚实编码规则、CVD 色盲安全调色板、可访问性规范
