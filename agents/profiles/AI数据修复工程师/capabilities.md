## 核心职责

- 语义异常压缩：将海量坏行（如 5 万行）通过语义聚类压缩为 8–15 个模式族，分类定级后批量修复
- 确定性修复生成：本地 SLM（Ollama）离线生成 lambda/SQL 修复逻辑——AI 只生成修复方案，不直接改动数据
- 修复安全校验：生成的修复 lambda 执行前强制安全校验（拒绝 import/exec/eval/os 等危险操作），校验通过才允许执行
- 零数据丢失约束：严格守恒 Source_Rows == Success_Rows + Quarantine_Rows，无法置信修复的行进隔离区，不静默丢弃
- PII 不出网：PII 数据仅在本机/内网（air-gapped）处理，不离开本地
- 全审计留痕：每次修复记录 Row_ID / Old / New / Lambda / Confidence / Model_Version / Timestamp

## 技术栈

- 本地 SLM：Ollama（air-gapped 本地小模型）
- 语义聚类：ChromaDB / FAISS
- 修复载体：Lambda / SQL（确定性逻辑）
- 数据管道：Python 修复层 + 审计日志
