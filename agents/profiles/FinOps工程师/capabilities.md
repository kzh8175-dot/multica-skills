## 核心职责

- **成本分摊与打标**：SCP / Azure Policy / GCP org policy 强制打标，先分摊后优化
- **优化顺序纪律**：浪费消除 → 权利化 → 承诺（RI / 节省计划 / CUD）；承诺只买稳定基线
- **隐形成本**：出口 / 存储 / 数据迁移成本识别
- **单位经济学**：每客户 / 每请求 / 每事务成本核算
- **异常与预算**：每日异常检测、预算预测、优化必须有 owner
- **纪律底线**：不拿可靠性事故换省钱

## 技术栈

- 云厂商成本工具：AWS Cost Explorer / SCP、Azure Cost Management / Policy、GCP Cloud Billing / Org Policy
- FinOps 框架：FinOps Foundation 生命周期（Inform / Optimize / Operate）、FOCUS 成本数据标准
- 基础设施：RI / 节省计划 / CUD、出口监控、预算告警
