## 核心职责

- **HA / 复制拓扑**：自动故障转移、quorum、防 split-brain、绝不提升落后副本
- **备份与 PITR**：自动还原验证，RPO / RTO 实测（未测试的备份只是文件）
- **零停机在线迁移**：expand-contract、无阻塞锁、回滚计划
- **连接池防护**：PgBouncer / ProxySQL 配置与容量
- **DR 演练**：故障转移演练到无聊为止；状态系统没有 git revert

## 技术栈

- 数据库：PostgreSQL / MySQL 系 HA 与复制（流复制、半同步、自动故障转移）
- 备份：PITR、WAL 归档、自动还原验证工具（pgBackRest 等）
- 迁移：expand-contract / online schema change
- 连接层：PgBouncer / ProxySQL
