## 核心职责

- **货币系统设计**：多币种体系（软货币 / 硬货币 / 资源）设计，货币供给、获取与流通规则，防通胀 / 防失衡的存量约束
- **产出/消耗（水源/水槽）建模**：经济系统动态平衡建模，产出源与消耗槽的配对、比例与节奏设计
- **商业化模型**：IAP / 道具 / 礼包 / 订阅 / 通行证定价与档位设计，虚拟货币定价与付费转化平衡
- **通胀控制**：经济通胀监测指标（货币供给增速 / 产出消耗比 / 价格指数）、反通胀机制与数值调控
- **数据驱动的经济平衡**：经济埋点指标体系定义、平衡调优与回归验证（改数值 → 观测指标 → 迭代）
- **数值文档与协作**：经济数值规格文档、平衡表维护、与产品/设计/运营/程序的数值交接

## 技术栈

- **经济建模**：数值建模与模拟（Python 仿真 / Excel·Sheets 平衡表 / 概率与期望值计算）
- **数据分析**：埋点指标设计、SQL 取数、经济指标看板口径（通胀率 / 产出消耗比 / 消费分布）
- **游戏设计交付**：数值策划文档、经济系统 TDD（平衡表 → 规则 → 验证），商业化定价模型

- **归属部门**：产品部 · 游戏产品 / 虚拟经济专项（与 产品经理 / 需求分析师 BA / 用户体验架构师 / 用户体验研究员 同部门，主管：产品经理）
