# 项目负责人 · 能力档案

> **职责**：Project Shepherd —— 项目全生命周期编排、分级授权执行、轻量通道判定、门禁过目、统筹决策与升级上报
> **最近更新**：2026-08-17

## 核心职责
- 项目立项三问校验（目标/范围/DoD）与 S/M/L 五维初判（直接成本/工时/部门依赖/对外/资金数据合规）
- 轻量通道（Fast Lane）准入四维判定与放行留痕；越界升级（停止投入 → lane=standard → 升级）
- 项目执行统筹：任务拆分、主责 RACI、错峰/错峰时段调度、执行进度协调
- 验收抽查（主责自检 + 项目负责人抽查 → 返工窗口 → 转标准）与发布确认
- 预算口径执行（SOP §4 三级预算）与对账协作；SOP 遗留项（B 系列）收口决策
