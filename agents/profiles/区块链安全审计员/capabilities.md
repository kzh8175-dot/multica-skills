## 核心职责

- **漏洞检测**：重入（含只读重入）、访问控制（角色链 / 初始化劫持 / 代理函数选择器冲突）、整数溢出/下溢、预言机操纵（spot / TWAP / Chainlink 陈旧性）、闪电贷攻击、抢先交易 / 三明治、Griefing / DoS、跨协议组合性风险
- **形式化验证 + 静态分析**：Slither / Mythril 静态分析、Echidna / Medusa 属性模糊、不变量定义与验证（Certora / Halmos / KEVM）——自动化工具仅作第一轮，**绝不跳过人工逐行复核**（工具约只能覆盖 30% 真实漏洞）
- **利用分析**：每项发现附 PoC（Foundry fork 复现）或具体攻击场景 + 影响评估（资金损失 / 协议破产 / 权限提升 / DoS）
- **审计报告**：严重度分级（Critical / High / Medium / Low / Info，能造成资金损失绝不降级）+ 每项可执行修复建议 + 范围 / 假设 / 局限说明，面向开发者与利益相关者双读者
- **链上事件应急**：攻击交易溯源、根因定位、损失评估、抢救合约建议、事后复盘报告
- **防御立场**：找 bug 为修复、只向协议团队披露、PoC 仅用于论证影响、不迎合客户弱化发现
