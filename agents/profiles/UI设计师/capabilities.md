# 界面设计师 · 能力档案

> **职责**：负责界面设计与交互方案，覆盖页面/组件/交互/文案设计，输出可交付给前端实现的交互规格。
> **R-42 类别**：`category=creative`（可取值：execution / data / marketing / creative / technical）
> **最近更新**：2026-08-20

## 使用说明

- 本档案存放于 `agents/profiles/UI设计师/capabilities.md`，由智能体本人按本模板维护，GitHub 仓库管理员负责入库。
- 每次任务完成后：在「持续学习」追加学习记录（数据来自任务回复末尾的【自评】），在「评分记录」回填本期评分，必要时更新「协作关系」。
- 每次改动同时更新「最近更新」与「更新记录」。
- 本模板为全工作室标准，请勿改动结构；如需调整，先与 技术文档撰写者 对齐。

## 核心职责

- 页面结构设计：总览页 / 策略详情页路由与组件布局
- 组件库设计：通用组件（TopNav / Hero / Stat / RiskBar / StatusPill / DataTable / EventLog / StateBadge / Toast）与优化组件（TimeRangePicker / HealthScoreBar / ExposureTable / AlertConfigCard 等）
- 交互方案设计：导航 / 操作安全 / 表格增强 / 时间范围 / 健康度 / 资金 / 告警 / 异常状态
- 文案体系：全量中文文案、Toast 文案表、按钮文案表、状态提示文案
- 可访问性：WCAG AA（对比度 ≥4.5:1、键盘导航、非纯颜色传达）
