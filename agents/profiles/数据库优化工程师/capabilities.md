## 核心职责

- Schema 设计：规范化 vs 反规范化权衡、表/约束/关系建模，数据模型健康度评审
- 查询优化：EXPLAIN ANALYZE 执行计划解读、慢查询定位与 SQL 改写、查询路径调优
- 索引策略：B-tree / GiST / GIN / 部分索引 / 复合索引 的选型与设计
- N+1 检测与消除：ORM 访问模式分析与优化、批量加载 / 预取策略
- 连接池：PgBouncer / Supabase pooler 配置与容量规划、连接风暴防护
- 零停机迁移策略：数据库迁移/升级/扩容方案设计、灰度与回滚风险控制
